# Gongpil 0.1.1

상태: `PRERELEASE`

0.1.1은 기존 0.1.0 MVP 위에 Client 접속기 표시 안정성과 Instance Part Window 사용성을 묶은 패키지 버전이다. Update Channel은 아직 없으므로 기존 설치 위 실시간 패치가 아니라 새 Installer 또는 portable ZIP으로 전달한다.

## 무엇이 달라졌나

- WinForms 접속기의 protected `CenterToScreen` 호출을 공개 `Location` 기반 중앙 배치로 교체했다.
- 실제 숨김 창을 표시해 `Shown` 이벤트를 통과하는 Client 회귀 테스트를 추가했다.
- 프로젝트·문서·편집기·공동 집필을 삭제되지 않는 Part Window로 정의했다.
- 작은 제목 바의 드래그 또는 `‹`·`›` 버튼으로 화면 내부 스냅 순서를 바꾼다.
- `—`로 Part Window를 44px 제목 레일로 최소화하면 남은 창이 즉시 넓어진다.
- 공동 집필의 컨텍스트·대화·요청을 Part Section으로 나눠 순서·접힘·높이를 조절한다.
- 컨텍스트는 기본 접힘, 대화와 요청은 넓은 기본 높이를 사용한다.
- Part Window와 Part Section 배치를 데이터 루트에 원자 저장하고 재시작 뒤 복원한다.
- 기존 레이아웃 v1의 순서·너비·접힘을 보존해 v2로 읽고 다음 저장 때 전환한다.

## 설치와 업데이트

- 설치형: `distribution/Gongpil-0.1.1-setup.exe`
- 포터블: `distribution/Gongpil-0.1.1-portable.zip`
- 각 파일과 같은 이름의 `.sha256` sidecar를 함께 확인한다.
- 기존 설정과 프로젝트 데이터는 재설치·제거에서 보존된다.
- 자동 updater와 Update Channel은 아직 `TARGET`이므로 실행 중인 0.1.0에 덮어쓰는 실시간 패치는 지원하지 않는다.

## 남은 제한

- 별도 OS 창과 자유 부동 창 대신 화면 내부 스냅만 지원한다.
- 문서·채팅의 이름 변경, 복제, 휴지통·복원 UI는 후속 작업이다.
- 프로젝트별 레이아웃, 여러 Instance Runtime 동시 관리, 자동 업데이트는 아직 없다.
- Windows x64만 패키징·검증하며 Installer는 상용 코드 서명 인증서로 서명되지 않았다.
