# Gongpil 0.1.0 MVP

상태: `PRERELEASE`

이 버전은 공필의 장기 전체 계획 중 “로컬 프로젝트 문서를 실제 화면에서 안전하게 작성하고 Windows에 설치·제거할 수 있는 최소 제품”을 검증한 선행 릴리스다.

## 지금 사용할 수 있는 기능

- Windows 클라이언트(접속기)에서 설치형 데이터 폴더와 시작 옵션 설정
- 기본 브라우저 인스턴스에서 프로젝트 생성·목록·열기
- Markdown, text, JSON 문서 생성·목록·읽기·편집·저장
- revision 기반 문서 청크 색인·검색과 UTF-8 byte 좌표 표시
- OpenAI API 또는 ChatGPT 구독 Codex 공급자를 이용한 공동 집필 채팅
- 페르소나 버전·작업 프로필 전환과 문서 청크 명시 선택
- 최근 10턴 기본 선택, 턴·메시지 청크·분류별 이전 대화 컨텍스트 선택
- 문서·대화 통합 예상 토큰, 포함 순서, 중복·예산 누락 사유 미리보기
- AI가 제안한 문서 변경의 전후 비교, 승인·거절과 적용 직전 revision 재검사
- 공급자별 토큰·API 예상 비용 정보와 민감정보 제거 개발 로그
- 안정적인 project ID·file ID와 SHA-256 revision
- expected revision 기반 동시 저장 충돌 방지
- 같은 볼륨 임시 파일, flush, rename을 이용한 원자 저장
- 저장 전 revision별 history 사본
- 프로젝트 밖 경로와 Windows 예약 이름 차단
- 일회용 launch URL, HttpOnly same-origin 세션과 loopback 동적 포트
- 포함 Node 24.18.0 LTS로 실행되는 Windows x64 포터블 ZIP
- 사용자 권한 Windows Installer, 시작 메뉴·선택 바탕 화면 바로가기와 제거
- 제거 후 사용자 데이터 보존과 재설치 데이터 재사용
- 상주 Client Runtime과 단일 Instance Runtime 종료·재시작
- Browser heartbeat ACK 3회 누락 시 Instance Runtime 자동 종료와 Client Runtime 복귀
- Client 홈의 Runtime 상태, 사용 가능 기능, 패치노트와 설정·정보 탭

## 설치형 사용법

1. `Gongpil-0.1.0-setup.exe`와 `.sha256`을 함께 받는다.
2. 배포 파일의 SHA-256을 확인하고 Setup.exe를 실행한다.
3. 시작 메뉴의 `Gongpil`을 연다.
4. 처음 뜨는 Client 홈에서 가능 기능과 패치노트를 확인하고, `설정` 탭에서 데이터 폴더를 정한 뒤 `인스턴스 시작`을 누른다.
5. 프로젝트를 만들고 `draft/1장.md` 같은 문서를 추가하여 저장한다.
6. 인스턴스 오른쪽 위 `인스턴스 종료`를 누르거나 Browser 창을 닫으면 Client Runtime의 접속기로 돌아간다. 창 닫힘은 약 30초 안에 감지한다.
7. `인스턴스 시작`으로 다시 열거나 `클라이언트 종료`로 프로그램을 끝낸다.

기본 프로그램 경로는 `%LOCALAPPDATA%\Programs\Gongpil`, 기본 데이터 경로는 `%LOCALAPPDATA%\Gongpil`이다. 시작 메뉴의 `Gongpil 설정`에서 데이터 경로와 접속기 표시 옵션을 다시 바꿀 수 있다. 경로를 바꿔도 기존 데이터를 자동 이동하지 않으며, 프로그램을 제거해도 설정과 데이터는 지워지지 않는다.

## 포터블 사용법

1. `Gongpil-0.1.0-portable.zip`과 `.sha256`을 함께 받는다.
2. 원하는 폴더에 압축을 풀고 `Gongpil.vbs`를 더블클릭한다.
3. 클라이언트(접속기)에서 고정된 `GongpilData` 위치를 확인하고 인스턴스를 시작한다.
4. 데이터는 압축을 푼 폴더의 `GongpilData`에 생긴다.
5. 이동·백업할 때는 `GongpilData`를 포함한 폴더 전체를 보관한다.

## 검증 근거

`npm run validate:release` 한 명령이 다음을 순서대로 실행하고 최종 배포 파일의 SHA-256 sidecar까지 다시 비교한다.

- NetworkRuntime 실제 HTTP/SSE 테스트 11개
- 실제 Client-Core 부트스트랩 테스트 5개
- 클라이언트 설정·실제 PowerShell 접속기 응답·Instance 재시작 테스트 8개
- Codex·OpenAI 공급자와 변경 제안 테스트 3개
- 개발 로그·사용 정보 UI 테스트 2개
- 문서 청크·색인·검색 테스트 5개
- 페르소나·이전 대화·컨텍스트 UI 테스트 8개
- 프로젝트·문서 MVP 테스트 5개
- 실제 포터블 ZIP 압축 해제·포함 runtime 2회 실행
- 실제 Setup.exe 설치·실행·제거·재설치·재실행·제거
- Bootstrap Contract, Network Contract, Network Map과 Code Map 검증

## 알려진 제한

- 클라이언트 접속기는 WinForms MVP이고, 작업 인스턴스는 내장 WebView가 아니라 기본 브라우저에서 열린다.
- Windows x64만 패키징·검증했다.
- 기존 임의 폴더 연결, 읽기 전용 잠금, rename/move/delete UI는 아직 없다.
- 이전 대화 원문·요약본·선택 청크 모드 중 자동 요약 모드는 아직 없다.
- ChatGPT 구독 Codex는 별도 격리 로그인이 필요하며, OpenAI API 사용료는 ChatGPT 구독과 별도다.
- 장기 기억, 플러그인 설치·격리 실행과 자동 업데이트는 아직 없다.
- Setup.exe는 상용 코드 서명 인증서로 서명되지 않아 Windows 경고가 나타날 수 있다.
- 상업 배포 전 Inno Setup 제작 도구 라이선스를 확인해야 한다.

이 제한들은 문서 저장 MVP의 데이터 형식이나 사용자 데이터 보존을 숨기지 않으며, README 체크리스트에서 후속 목표로 계속 추적한다.
